# The demo loop

`T5Demo.oxp` turns Oolite into a show reel: start a new commander (Normal Start) and the
ship launches from Lave station, flies out for 12 s, then the docking computer takes it
back in to the Blue Danube. Eight seconds after docking it launches again, round and round.
The docking computer is awarded at start-up if the ship hasn't got one.

To use it, copy the folder into the Oolite drawer's `AddOns` folder (`Oolite/AddOns/T5Demo.oxp`).
Take it out again to play normally.
