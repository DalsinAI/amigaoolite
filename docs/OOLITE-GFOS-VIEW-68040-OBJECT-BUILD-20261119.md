# Oolite GFOS original view object build — 19 November 2026

This is a **compiler/object-only** qualification. It is NOT a full Oolite executable, a startup test or an RC.

Pinned upstream Oolite `21978c37b2f11c8664adf3e2062efc1d0c875979`, original `src/SDL/MyOpenGLView.m`, patch `patches/oolite/0015-gfos-view-early-prefs-fallback.patch` applied to an isolated copy. Cross-compiled using OpenAmigaGCC 16.2 (`-m68040 -m68881 -noixemul`, Objective-C GNU11) with GFOpenRTG SDL3/OpenAL/GLU headers, GNUstep Foundation headers, pinned Oolite headers, and historical SpiderMonkey source/include *for standalone engine-build diagnostics only*. Tested object checksum: `aa559ab523c1f641a955783d07e4103aa2cf1529478d6e65cc69802366a56240`.

The GCC 16 target `<tgmath.h>` references `csinl`, `ccosl`, and `ctanl` even when selecting **real float** operations, while the target `<complex.h>` declares those complex long-double functions only behind the Cygwin guard. The build-only `build/gfos-amiga-tgmath-compat.h` adds the missing prototypes behind `__amigaos__`. The isolated real-valued `sin(float)+cos(float)` test resolves to the existing target `_sinf`/`_cosf`, **not** to complex math or fabricated stub implementations. The compatibility header must not be presented as evidence that complex-long-double arithmetic itself is supported or linked. With this header and original `OO_VERSION_FULL`, `OO_BUILDER`, `OO_BUILD_DATE` version defines, patched `MyOpenGLView.m` compiled as a native AmigaOS object without errors.

The actual full original game executable is still blocked on reconstructing complete native libraries and source dependency paths. The historical `build/full-link.mk` was built around standalone SpiderMonkey/legacy JSAPI; the production GFOS design instead requires canonical shared `javascript.library` with real Oolite host-class integration. The restored SpiderMonkey source and build are **isolated diagnostic tools**, not an approved release engine. No 68040 guest run of this newly compiled view or title screen is claimed.
